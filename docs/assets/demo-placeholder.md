# Demo recording placeholder

The README `## Demo` section embeds `docs/assets/demo.gif`. That recording is still pending; this file records exactly what it must show so anyone can produce it.

## Requirements

- One permission-gate confirmation: a `pibash` call paused at the gate, reviewed, then approved and executed.
- One dashboard render: a session card from the `pi sessions` dashboard showing token spend.
- About 15 seconds total, one terminal window, no editing needed.
- Format: asciinema cast or GIF, at most 3 MiB, saved as `docs/assets/demo.gif`.
- Plain terminal content: no emoji, no secrets; record in a scratch directory so paths need no scrubbing.

## Why these two beats

The gate confirm shows the fail-closed trust model; the dashboard card shows the measured token economy. One asset, both differentiators.
