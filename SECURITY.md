# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest `v1.x` tag | Yes |
| Older tags | Best effort |

Security fixes target the latest tagged release. Older tags get best-effort fixes only; upgrade to the latest tag before reporting.

## Reporting a Vulnerability

Report privately via GitHub Private Vulnerability Reporting:

https://github.com/nurmdrafi/pi-native/security/advisories/new

Or email the maintainer directly: nurmdrafi2014@gmail.com

Do not open a public issue, pull request, or discussion for a vulnerability.

Include the affected tag or commit, reproduction steps, and impact. Out-of-scope reports get a short reply saying so.

## Scope

The harness code and native tools in this repository. Vulnerabilities in dependencies belong to their upstream projects; a private heads-up is still welcome.

## Response Expectations

- Acknowledgment within a few days.
- Coordinated disclosure: the fix ships before details are published, on a timeline agreed with you.
