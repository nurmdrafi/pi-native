# Permission-gate guidance

Treat a block as final for that operation. Read the message, follow its stated remedy, or ask if you cannot proceed. Do not retry the blocked operation in another form.

For read windows and edit anchors, follow [Tool use: File lookup](tool-use.md#file-lookup). To investigate an apparent misfire, use the [harness-watch workflow](../docs/harness-watch.md).

Written guidance does not change what the gate enforces. For settings, see the [rule catalog](../extensions/README.md#configuring-rules); executable checks stay in [the permission-gate extension](../extensions/permission-gate/rules/).
